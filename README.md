# 微信公众号文章工作台

把公众号文章拆成可验证的结构化内容块，在一个界面里完成编辑、手机预览、微信兼容 HTML 预览和导出前检查。

## 已实现

- 成都开学季课包特惠与 K11 青少年暑期集训内置文章
- 文章大纲与结构化块编辑
- 正文、章节、图片、提示、信息表、排期表和须知组件
- 内容块新增、复制、删除、上移和下移
- 粘贴原文并自动拆分结构
- 本地图片关联与浏览器草稿自动保存
- React 手机预览与最终导出 HTML 预览
- 原文一致性、图片完整性和微信 HTML 兼容性检查
- 复制微信 HTML 与下载独立 HTML 文件
- 桌面、平板和移动端响应式界面

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。

```bash

```

## 内容安全模型

文章以 `ArticleDocument` 为唯一内容源：

- `sourceText` 保存导入时的文字基线。
- `blocks` 保存编辑结构。
- React 预览与微信 HTML 分别从 `blocks` 渲染。
- 校验器比较当前可见文字和 `sourceText`，只报告差异，不自动改写内容。

微信导出器位于 `src/features/export/wechatExporter.ts`，只输出内联样式和受控标签。长文本使用独立 `<p style="margin:0;...">`，不会把应用 class、React 属性、脚本或外部样式带入导出结果。

## 图片说明

K11 示例图位于 `public/assets/k11/`。本地图片可用于工作台预览，但复制到微信公众号后台后仍需在微信编辑器内重新上传或替换；校验器会保留这项提醒。
